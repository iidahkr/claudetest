# サービス設計書: AIツールNavi

## 日本語特化AIツール比較ディレクトリサイト

---

## 1. サービス概要

**AIツールNavi** は、日本語ユーザー向けにAIツールを比較・検索できるキュレーション型ディレクトリサイト。

「結局どのAIツールを使えばいいの？」を解決する。

### なぜディレクトリサイトか

米国Indie Hacker界で最も再現性が高く、低コストで収益化できるモデル。
代表例の [OpenAlternative](https://openalternative.co/) は1人開発・月$6,000収益・運用コスト月$50-100。

### なぜ「AIツール」か

- 毎週のように新しいAIツールがリリースされ、情報が追いつかない
- note.com上に「AIツール比較」記事が大量にあるが、すべて**静的な記事**
- **フィルタ・検索・レビュー付きの構造化されたディレクトリ**が日本語で存在しない
- AIツール企業の広告予算は潤沢 → 有料掲載の高い支払い意欲

```
決済:           Stripe（有料掲載の課金）
```

### なぜSSG（静的生成）中心か

- ツールデータは頻繁に変わらない → ビルド時に静的生成で十分
- SEOに最適（HTMLが事前生成されている）
- Vercelの無料枠で十分ホスト可能
- ISR（Incremental Static Regeneration）で定期的に再生成

## 6. SEO戦略（最重要）

ディレクトリサイトの生命線はSEO。以下の3層構造で攻める。

### Layer 1: ツール個別ページ（ロングテール）

```
/tools/chatgpt     → 「ChatGPT 評判」「ChatGPT 料金」
/tools/midjourney   → 「Midjourney 使い方」「Midjourney 料金」
/tools/cursor       → 「Cursor エディタ」「Cursor 評判」
```

- 各ツール名 × 「評判/料金/使い方/比較」で流入
- 200ツール登録 → 200ページ × 4キーワード = 800キーワードをカバー

### Layer 2: カテゴリページ（ミドルテール）

```
/categories/image-generation → 「画像生成AI おすすめ」
/categories/writing          → 「AI 文章作成 ツール」
/categories/coding           → 「AIコーディング ツール」
```

- カテゴリ × 「おすすめ/比較/無料」で流入
- 14カテゴリ × 3キーワード = 42キーワード

### Layer 3: ブログ記事（ビッグキーワード）

```
/blog/best-image-ai-2026
→ 「画像生成AI おすすめ 2026」（月間40,000検索）

/blog/chatgpt-vs-claude-vs-gemini
→ 「ChatGPT Claude 比較」（月間15,000検索）

/blog/free-ai-tools
→ 「AI 無料 ツール」（月間33,000検索）
```

- 月2-4本の比較記事を投稿
- 記事内からツール詳細ページへ内部リンク

### 技術的SEO

- **SSG**: 全ページ静的生成 → クロール・インデックス最速
- **構造化データ**: JSON-LD で Product, Review, AggregateRating を出力
- **OGP画像**: Vercel OG で動的生成（SNSシェア時に目立つ）
- **サイトマップ**: 自動生成、Google Search Console に登録
- **内部リンク**: ツール→カテゴリ→ブログの相互リンク構造

```

```

## 10. 成功のための原則

### OpenAlternativeから学ぶ3つの教訓

1. **48時間でMVPをローンチせよ**
   完璧を目指さない。最小限の機能で公開し、フィードバックで改善する。

2. **SEOファーストで設計せよ**
   PDF.aiのソロ開発者は「SEO一点突破」で$3.6M ARRを達成。
   すべてのページ設計はSEOを最優先に。

3. **先に価値を提供し、後から課金せよ**
   無料で掲載 → トラフィック実績を作る → 有料掲載を提案。
   OpenAlternativeも初日に$99の有料掲載を売った。
