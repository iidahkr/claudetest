# サービス設計書: KonDate AI（コンダテAI）

## AI献立自動提案サービス

---

## 1. サービス概要

**KonDate AI** は、AIが毎日の献立を自動提案し、買い物リストを生成するWebサービス。

「今日何作ろう？」という毎日の悩みをAIで解決する。

### コアバリュー

- 冷蔵庫の食材・予算・好み・人数に応じた献立をAIが即座に提案
- 栄養バランスを考慮した1週間分の献立を一括生成
- 買い物リストの自動生成（スーパーで見ながら使える）
- レシピの手順表示（調理中に見ながら使える）

## 2. なぜこのサービスか（市場分析）

### 課題の普遍性

| 指標 | データ |
|------|--------|
| 共働き世帯数 | 約1,200万世帯 |
| 「献立 悩む」の月間検索数 | 約40,000回 |
| 「今日の献立」の月間検索数 | 約200,000回 |
| 食関連アプリ市場規模 | 年間約500億円 |

### 既存サービスとの差別化

| サービス | 弱点 | KonDate AIの優位性 |
|---------|------|-------------------|
| クックパッド | レシピ検索のみ、献立提案なし | AIが食材から献立を自動構成 |
| me:nu | 提案精度が低い、UI古い | GPT活用の高精度提案、モダンUI |
| Racook | 機能が限定的 | パーソナライズ + 買い物リスト統合 |
| ChatGPT直接利用 | 毎回プロンプト入力が面倒 | ワンタップで献立生成、履歴管理 |

### 選定理由

1. **毎日使う** = 高い継続率（チャーン率が低い）
2. **主婦/主夫層** = 口コミ拡散力が高い（ママ友ネットワーク）
3. **節約効果** = 月980円は食費削減効果で十分ペイする
4. **SEO親和性** = レシピコンテンツはSEOに強い
5. **技術的に実現可能** = 1人で開発・運用できる規模

## 4. ユーザーストーリー

### ペルソナ1: 共働き主婦（30代）

> 「仕事帰りにスーパーで何を買えばいいか分からない。
> 毎日献立を考えるのが本当にストレス。
> 冷蔵庫にある食材で作れるものを教えてほしい。」

**利用フロー:**
1. 帰宅前にアプリを開く
2. 冷蔵庫の食材を入力（または前回の残りから自動表示）
3. AIが「主菜 + 副菜 + 汁物」の献立を3パターン提案
4. 気に入った献立を選択
5. 足りない食材が買い物リストに自動追加
6. スーパーで買い物リストを見ながら購入
7. 帰宅後、レシピ手順を見ながら調理

### ペルソナ2: 一人暮らし大学生（20代）

> 「自炊したいけど何を作ればいいか分からない。
> コンビニ飯ばかりで健康が心配。予算は月3万円以内。」

**利用フロー:**
1. 月の食費予算を設定（3万円）
2. AIが予算内で1週間分の献立を一括提案
3. まとめ買いリストを生成
4. 週末にまとめ買い → 平日は手順に沿って調理

## 6. 技術設計

### 技術スタック

```
フロントエンド:  Next.js 15 (App Router) + TypeScript
UIライブラリ:    Tailwind CSS + shadcn/ui
バックエンド:    Next.js API Routes (Route Handlers)
データベース:    Supabase (PostgreSQL)
認証:           Supabase Auth (Google, Email)
AI:             OpenAI GPT-4o-mini API
決済:           Stripe Subscriptions
ホスティング:    Vercel
画像:           Cloudinary (レシピ画像)
```

### 選定理由

- **Next.js + Vercel**: デプロイが簡単、SSR/SSGでSEO強い、無料枠が大きい
- **Supabase**: PostgreSQL + Auth + Realtime が無料枠で十分、RLS対応
- **GPT-4o-mini**: コスト効率が良い（1リクエスト約0.5円）、日本語品質十分
- **Stripe**: 日本対応済み、サブスク管理が容易
- **Tailwind + shadcn/ui**: 高速UI開発、モバイルファースト対応

### データベース設計

```sql
-- ユーザー（Supabase Auth連携）
profiles
├── id: uuid (PK, auth.users.id)
├── display_name: text
├── family_size: int
├── budget_monthly: int
├── dietary_preferences: jsonb  -- アレルギー、好み等
├── plan_type: text             -- free / standard / family
├── stripe_customer_id: text
├── created_at: timestamptz
└── updated_at: timestamptz

-- 食材マスタ
ingredients
├── id: uuid (PK)
├── name: text
├── category: text              -- 肉/魚/野菜/調味料等
├── default_unit: text          -- g/個/本等
└── calories_per_100g: int

-- ユーザーの手持ち食材
user_ingredients
├── id: uuid (PK)
├── user_id: uuid (FK → profiles)
├── ingredient_id: uuid (FK → ingredients)
├── quantity: decimal
├── unit: text
├── expiry_date: date
└── updated_at: timestamptz

-- 献立提案
meal_plans
├── id: uuid (PK)
├── user_id: uuid (FK → profiles)
├── date: date
├── meal_type: text             -- breakfast/lunch/dinner
├── menu_data: jsonb            -- AI生成の献立データ
│   ├── main_dish: {name, ingredients, steps, time, calories}
│   ├── side_dish: {name, ingredients, steps, time, calories}
│   └── soup: {name, ingredients, steps, time, calories}
├── is_favorite: boolean
├── created_at: timestamptz
└── updated_at: timestamptz

-- 買い物リスト
shopping_lists
├── id: uuid (PK)
├── user_id: uuid (FK → profiles)
├── week_start: date
├── items: jsonb                -- [{name, quantity, unit, checked}]
├── created_at: timestamptz
└── updated_at: timestamptz
```
